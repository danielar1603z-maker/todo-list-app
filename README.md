# Lista de Tareas

Aplicación web para gestionar tareas diarias: agregar, marcar como completadas, filtrar y eliminar. Los datos se guardan en el navegador con `localStorage`, así que las tareas no se pierden al recargar la página.

## Demo

Abre `index.html` en tu navegador para probarla — no necesita instalación ni backend.

## Funcionalidades

- Agregar tareas nuevas
- Marcar tareas como completadas
- Filtrar por: todas / pendientes / completadas
- Eliminar tareas individuales
- Borrar todas las completadas de una vez
- Contador de tareas pendientes
- Persistencia de datos con `localStorage`
- Diseño responsive

## Tecnologías

- HTML5
- CSS3 (sin frameworks)
- JavaScript (vanilla, sin librerías)

## Qué aprendí construyendo este proyecto

- Manipulación del DOM y delegación de eventos
- Persistencia de datos en el navegador con `localStorage`
- Manejo de estado en JavaScript puro (sin frameworks)
- Diseño de una interfaz accesible (roles ARIA, foco visible)
